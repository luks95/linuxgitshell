# LinuxGitShell 0.1.0 — Foundation

LinuxGitShell 0.1.0 is the first development release of the reusable Git core and the minimal
desktop inspector. It targets KDE Plasma 6 on Manjaro/Arch Linux and is intended for evaluation and
continued development, not production Git workflows.

This document describes the immutable `v0.1.0` tag. The development branch has moved into Phase 2;
see [`STATUS.md`](../../STATUS.md) for current capabilities rather than interpreting the limitations
below as the state of `main`.

## Highlights

- Asynchronous, cancellable Git process execution with typed failures, raw diagnostics, separate
  arguments, timeouts, and credential-safe logging.
- Discovery of normal and bare repositories, linked worktrees, submodules, separate Git directories,
  branches, detached HEAD, upstream divergence, remotes, and operations in progress.
- Strict porcelain v2 status parsing and asynchronous status reads for staged, unstaged, untracked,
  ignored, renamed, copied, submodule, and conflicted states.
- Read-only Git configuration inspection with scope and origin while redacting credential-bearing
  diagnostic data.
- A Qt/KF6 desktop window showing repository identity, status summary, configuration, reloads, and
  inspectable failures without blocking the UI.
- English source strings, a compiled Spanish catalog, and isolated unit, integration, and offscreen
  application tests.

## Important limitations

- Dolphin context menus and overlays are not implemented.
- The application does not stage, commit, modify configuration, or perform any other mutating Git
  operation.
- External and network mount performance has not been characterized; only path-correct discovery is
  in scope for this release.
- Packaging for Arch/Manjaro and other distributions is not available yet. Build from source with
  the dependencies listed in `README.md`.
- The release tag is annotated but is not cryptographically signed because no GPG signing identity
  was available in the release environment.

## Verification

Release artifacts are built and tested from the exact `v0.1.0` tag. The release contains a source
archive named `LinuxGitShell-0.1.0.tar.gz` and `SHA256SUMS`; verify it with:

```bash
sha256sum --check SHA256SUMS
```

The source archive contains no vendored dependencies. Configure, build, and test it offline after
installing the system dependencies documented in `README.md`.
