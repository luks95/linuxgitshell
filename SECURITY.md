# Security Policy

## Supported versions

LinuxGitShell is pre-release software. Maintainers accept private reports for the current development
series but do not yet promise production support or a long-term maintenance window.

| Version | Private security reports |
| --- | --- |
| `0.1.x` | Accepted |
| Older versions | Not supported |

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue, discussion, or log. Use the private
security-reporting form at
<https://github.com/luks95/linuxgitshell/security/advisories/new>. Avoid including credentials,
private paths, or unrelated repository contents beyond what is strictly required to reproduce the
issue.

A complete report should describe the affected revision, impact, reproduction conditions, and any
suggested mitigation. Maintainers will acknowledge receipt, coordinate a fix and disclosure window,
and credit the reporter unless anonymity is requested. The initial response target is three business
days; progress updates should follow at least every seven days while investigation remains active.
