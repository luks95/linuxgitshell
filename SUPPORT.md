# Support

LinuxGitShell is pre-release software. The public `v0.1.0` application provides read-only repository
inspection. The development branch also provides a minimal Dolphin action for opening one local
selection in the external application. Repository-aware menus, overlays, and mutating Git workflows
are not available yet.

For public, non-sensitive project communication:

- Use the bug template for reproducible defects.
- Use the feature template for product suggestions.
- Use the design template for architectural changes.
- Check [`STATUS.md`](STATUS.md) before reporting a missing feature from the development branch.
- Use [GitHub Discussions](https://github.com/luks95/linuxgitshell/discussions) for usage questions
  and community conversation.
- Follow `SECURITY.md` for vulnerabilities; never report them publicly.

Include the exact LinuxGitShell revision, distribution, Qt/KF6, Dolphin, and Git versions. Remove
usernames, private paths, repository contents, remote URLs, tokens, keys, and other secrets from logs.
